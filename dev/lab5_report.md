# Отчёт по лабораторной работе

**Тема:** Передача BPSK и символьная синхронизация

## Цель работы
Сформировать на передатчике пакет BPSK с преамбулой и псевдослучайными данными, передать его между двумя Adalm Pluto SDR и на приёме выполнить символьную синхронизацию: найти начало пакета и момент отсчёта внутри символа с помощью согласованного фильтра.

## Краткое содержание
Используется та же схема из двух SDR, что и в лабораторной работе №4 (каналы `down` 433 МГц и `up` 434 МГц, отправка TX-буферов по временным меткам). Вместо постоянного уровня в чётных буферах теперь передаётся пакет BPSK, нечётные буферы по-прежнему нулевые.

Пакет занимает один буфер 1920 отсчётов. При 10 отсчётах на символ это 192 символа:

| Часть пакета | Символов | Содержимое |
|--------------|----------|------------|
| Преамбула | 13 | код Баркера-13: `1 1 1 1 1 0 0 1 1 0 1 0 1` |
| Данные | 179 | биты PRBS-9 (x⁹ + x⁵ + 1), начальное состояние `0x1FF` |

Генератор PRBS-9 сбрасывается в начале каждого пакета, поэтому все пакеты одинаковые.

### Формирование сигнала на передатчике
1. Бит переводится в уровень: 1 → +1500, 0 → −1500 (только I, Q = 0).
2. Повышение частоты дискретизации: символ ставится в первый отсчёт из 10, остальные 9 — нули.
3. Свёртка с импульсной характеристикой формирующего фильтра. Импульс прямоугольный — 10 единиц, поэтому каждый символ растягивается на 10 отсчётов.
4. Сдвиг `<< 4` под 12-битный ЦАП и запись в буфер в формате I, Q, I, Q, ...

### Обработка на приёмнике (`read.py`)
1. **Поиск пакетов по энергии.** Амплитуда сглаживается скользящим средним на 64 отсчёта, порог берётся посередине между уровнем шума и уровнем сигнала. Фронт выше порога — примерное начало пакета.
2. **Корреляция с преамбулой.** Вокруг найденного фронта (±100 отсчётов) считается корреляция с преамбулой, растянутой на 10 отсчётов на символ. Положение пика модуля корреляции даёт точное начало пакета.
3. **Согласованный фильтр.** Импульс на передатчике прямоугольный, поэтому согласованный фильтр — сумма 10 соседних отсчётов. На выходе каждый символ превращается в треугольник с вершиной в конце символа.
4. **Выбор момента отсчёта.** Выход фильтра разбивается на блоки по 10 отсчётов (по одному на символ). Для каждого сдвига внутри символа считается энергия по всем символам пакета, выбирается сдвиг с максимальной энергией. Из каждого символа берётся один отсчёт в этот момент.

Частотная и фазовая синхронизация на этом этапе не выполняются, поэтому из-за разницы частот генераторов двух SDR точки созвездия вращаются и ложатся на окружность, а не в две точки ±1.

### Ключевые параметры
| Параметр | Значение |
|----------|----------|
| Sample Rate | 1 МГц |
| Отсчётов на символ (SPS) | 10 |
| Символьная скорость | 100 кбод |
| Модуляция | BPSK |
| Размер пакета | 1920 отсчётов, 192 символа |
| Преамбула | Баркер-13 |
| Данные | PRBS-9, 179 бит |
| Формирующий фильтр | прямоугольный, 10 отсчётов |
| Согласованный фильтр | прямоугольный, 10 отсчётов |
| Gain RX / TX | 20 / 89 |

### Запуск
```bash
# downlink: SDR №1 передаёт, SDR №2 принимает на 433 МГц
./main tx usb:1.3.5 down
./main rx usb:1.5.5 down

# обработка
python3 read.py down
```
Скрипт выводит число найденных пакетов и распределение выбранного момента отсчёта по пакетам, строит I, Q и амплитуду, созвездие после синхронизации и гистограмму момента отсчёта.
