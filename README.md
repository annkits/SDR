# SDR — Производственная практика по программно-определяемому радио

Репозиторий содержит материалы производственной практики по работе с **Software-Defined Radio (SDR)** на базе **Adalm-Pluto**.

Основные направления:
- Работа с **GNU Radio Companion**
- Приём и анализ реальных радиосигналов (FM, Wi-Fi)
- Прямая работа с устройством через **SoapySDR** + поддержка **timestamp**
- Сборка и использование необходимых библиотек (libiio, libad9361, SoapySDR, SoapyPlutoSDR)

### Lab 2 — Приём Wi-Fi сигнала

### Lab 4 — Две SDR: прямой и обратный каналы
Используются две SDR: одна передаёт, другая принимает, отправка TX-буферов планируется по временным меткам FPGA. Есть два канала:

| Канал | Частота | Направление |
|-------|---------|-------------|
| `down` (downlink, прямой) | 433 МГц | SDR №1 → SDR №2 |
| `up` (uplink, обратный) | 434 МГц | SDR №2 → SDR №1 |

Передатчик отправляет буферы по 1920 отсчётов, чередуя сигнал и тишину, поэтому на приёме амплитуда имеет вид прямоугольных импульсов (1920 отсчётов «вкл», 1920 «выкл», период 3.84 мс при 1 МГц). Каждый буфер планируется на 4 мс вперёд относительно timestamp текущего RX-буфера.

**Сборка:**
```bash
cd dev
mkdir -p build && cd build
cmake .. && make
```

**Запуск** (каждая команда в своей консоли, URI устройств — из `SoapySDRUtil --find`):
```bash
# downlink: SDR №1 передаёт, SDR №2 принимает на 433 МГц
./main tx usb:1.3.5 down
./main rx usb:1.5.5 down

# uplink: SDR №2 передаёт, SDR №1 принимает на 434 МГц
./main tx usb:1.5.5 up
./main rx usb:1.3.5 up
```
Формат: `./main <rx|tx> <uri> <down|up>`. Сначала запускается TX, затем RX; остановка — Ctrl+C.  
Приёмник пишет I/Q-сэмплы (int16, little-endian) в `rx_down.pcm` или `rx_up.pcm` в текущей папке.

**Визуализация:**
```bash
python3 dev/read.py down        # или up, или путь к .pcm файлу
```
Скрипт выводит статистику амплитуды и строит I, Q и |I + jQ| для 2 000 000 отсчётов вокруг самого сильного сигнала.

В `dev/rx_down.pcm` лежат тестовые данные, принятые SDR по каналу downlink (RX Gain = 20).
